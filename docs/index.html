Fifteen seconds of Cubit

See it move

On your phone

Six faces, and they wrap

On the cube, an arrow can run over the edge onto the next face, so the arrow blocking you might start round the back. Drag to turn the cube, pinch to zoom, and plan a few moves ahead.

  • Levels start at 10×10 per face with about a hundred arrows and grow to 18×18.
  • Each level buries the pink arrow a little deeper.
  • Leave mid-level and it's saved. Pick it up from the home screen.

One tap from the home screen

Clean mode

The whole screen is the cube. It turns to glass in your colours, so you can see the back faces through the front, with the far arrows fading.

  • Unlimited lives and all the time you want. An X in the corner is the only button.
  • Tap with two fingers to take back a move.
  • Clean runs get their own mark on the global board.
Everything else

Out of the way until you want it

Scores you can trust

Rankings are optional. When they're on, the server replays your taps on the same cube and works out the score itself. You can watch any run on the board play back.

Daily and weekly

A 12×12 cube every day and a 16×16 challenge every week, the same for everyone, each with its own board. Share a link and a friend gets the same cube.

Five powerups

Scan lights up every free arrow. Shield, Freeze, Spare life and Undo save a bad moment. One of each per level, and you can switch any of them off.

Badges that pay off

Seventeen badges, from your first win to a perfect run on Expert. Six colourways open as you earn them, and a daily streak keeps you coming back.

Your colours

Twelve colourways, your own arrow colour and thickness, and a stripe on the pink arrow if colour alone doesn't work for you.

Race a ghost

On the daily and weekly cubes, the leader's run plays out faintly on your cube as you go. Beat it to the pink arrow.

Packs and par

Forty picked cubes in four packs, from tiny 5×5 puzzles to 18×18 monsters. Every cube has a par: the fewest taps that can win it.

Sound and touch

Real split-flap clacks, a soft swoosh for every arrow, a quiet soundtrack, and a vibration you can feel when you bump.

Install

On your phone in a minute

Cubit isn't on the Play Store, so you install the file yourself. Android asks once whether your browser may install apps.

  1. Download Cubit.apk on your phone with the button on this page.
  2. Open it from your downloads. If Android asks, allow your browser to install apps.
  3. Tap Install, then open Cubit. A short how-to-play cube is waiting.

The source is on GitHub under the MIT licence. Every release is signed with the same key and lists the file's SHA-256 checksum, so updates install over the top and keep your progress.

Questions

Before you download

Is it really free?

Yes. Every level, mode and powerup is in the free download. There are no ads and nothing to buy.

Why isn't it on the Play Store?

It's a one-person project, published on GitHub instead. You install the APK like any other app, and updates install over the top.

Is the APK safe?

You can read every line of the source on GitHub, each release is signed with the same key, and the release page lists the file's SHA-256 checksum so you can check what you downloaded.

Does it need the internet?

Only for the optional global rankings. You choose on first launch, and everything else works offline. On GrapheneOS, allow Cubit's Network permission if you want rankings.

What does the leaderboard know about me?

The name you pick, your XP, and your ranked runs, including the taps, so the server can check them. It stores no email or account, and the app runs no analytics.

How hard does it get?

The first levels ease you in. After that the cubes grow and the pink arrow sits deeper each time. On Expert, one bump ends the level.
